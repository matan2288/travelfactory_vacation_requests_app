1. Submission (Requester)
An employee submits a vacation request with a future start date, an end date, and an optional reason. The request enters a Pending status.

2. Review (Validator)
A manager (Validator) views all submitted requests across the team, with the ability to filter by status and requester.

3. Decision (Validator)
The Validator resolves the pending request via one of two actions:

Approve: The request is marked Approved and becomes permanently locked (cannot be edited).

Reject: The Validator inputs a mandatory explanation comment, and the request is marked Rejected.

Core System Rules:

A single user cannot have overlapping vacation requests.

Start dates cannot be in the past.

Only users with Validator roles can make approval or rejection decisions.
